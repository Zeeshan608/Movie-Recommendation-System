## ✨ Features

* 🎥 **Movie Recommendations** — Discover movies based on your selection.

* 🖥️ **Interactive Interface** — Simple and user-friendly Streamlit application.
* ⚡ **Pre-trained Model** — Loads saved model artifacts for recommendations.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Zeeshan608/Movie-Recommendation-System.git
cd Movie-Recommendation-System
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Application

```bash
python -m streamlit run app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.

## ☁️ Deploy on Streamlit Community Cloud

1. Push your project files to GitHub.
2. Visit [Streamlit Community Cloud](https://share.streamlit.io/).
3. Sign in and connect your GitHub account.
4. Select this repository and choose `app.py` as the entry point.
5. Click **Deploy**.

Ensure the required model and dataset files are accessible to the deployed application.
